# Simple Interest Calculator

A simple Bash script that calculates simple interest based on user input.

## Description
This project contains a shell script (`simple-interest.sh`) that prompts the
user for three input fields and computes the simple interest.

## Input Fields
- **Principal** — the initial amount of money
- **Rate of Interest** — the annual interest rate (in percent)
- **Time Period** — the duration in years

## Formula
Simple Interest = (Principal × Rate of Interest × Time Period) / 100

## Usage
```bash
bash simple-interest.sh
```

## Example
Enter the principal: 10000
Enter the rate of interest: 5
Enter the time period: 2
The simple interest is: 1000
